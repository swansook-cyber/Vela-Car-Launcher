# Vela Car Launcher

Android 12 landscape dashboard launcher for internal head-unit testing. Package: `net.velalab.carlauncher`.

The dashboard reads GPS fixes for speed, accuracy, bearing, moving distance and moving time. Speed clears after five seconds without a fresh fix. Weather uses the [Open-Meteo Forecast API](https://open-meteo.com/en/docs) at the latest accepted GPS location and caches the last successful response. Navigation launches a detected navigation app; it does not embed Google Maps or invent a destination. Quick Apps use installed app icons and can be shown, hidden and reordered in Settings. VelaRedio is discovered by installed app label; media controls appear only when its active MediaSession advertises the matching actions and the user grants notification listener access.

Settings includes a link to Android's Home app selection screen. The app never selects itself as default. To restore the previous launcher, open Settings → Choose default home app and select the previous Home app. To return from a navigation app before changing the default launcher, use Android Recents or Back.

Build for internal QA with `gradle :app:testDebugUnitTest :app:assembleDebug`. The debug APK is never a release artifact. Release signing requires the original `vela-release.jks` file, alias `vela-store`, and `VELA_KEYSTORE_PATH`, `VELA_STORE_PASSWORD`, `VELA_KEY_PASSWORD` environment variables. GitHub Actions expects secrets `VELA_RELEASE_JKS_BASE64`, `VELA_STORE_PASSWORD`, and `VELA_KEY_PASSWORD`; it skips signed release build when any are absent. No keystore is generated by this project.

Physical vehicle QA is still required for GPS under real driving, launcher selection and rollback, VelaRedio interoperability, reverse camera, MCU, and the head unit's resolution and DPI. Do not use the debug APK in Vela App Store.
